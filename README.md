# Prva Android Aplikacija – Hello World!

Osnovna Android aplikacija, razvita v okolju Android Studio z uporabo jezika **Java**. Namen projekta je spoznavanje zgradbe Android aplikacije, dela z uporabniškim vmesnikom (UI) v pogledu Design in XML ter implementacija osnovnih interakcij (Toast in Snackbar).

---

## 📱 Funkcionalnosti aplikacije

- **Uporabniški vmesnik (ConstraintLayout):**
  - Oblikovanje besedil z gradnikom `TextView` (sprememba besedila, sloga `bold` in velikosti `34sp`).
  - Uporaba osnovnih gradnikov: `Button`, `CheckBox` in `FloatingActionButton` (FAB).
  - Pravilna umestitev elementov z uporabo omejitev (*constraints*).
- **Lokalizacija in resursi:**
  - Vsa besedila so ločena od XML postavitve in shranjena v datoteki `strings.xml`.
- **Interakcija in obvestila:**
  - **Prikaz Toast sporočila:** Ob kliku na gumb se prikaže obvestilo *"My first Android Studio application!"*.
  - **Prikaz Snackbar sporočila:**
    - Standardni `Snackbar` ob kliku na FAB gumb z besedilom *"Just another option for button"*.
    - Prilagojena različica sporočila, postavljena na sredino zaslona z oblikovanjem, podobnim Toast obvestilu.
